# Telegram Group Admin Bot — карта фаз

Пофазный план разработки бота для администрирования Telegram-групп (аналог ChatKeeper).
Каждая фаза — самодостаточный промпт для AI-агента, проверяемый end-to-end.

**Стек (единый на все фазы):** Python 3.12 · aiogram 3 · PostgreSQL · Redis · Docker Compose · webhook · i18n (ru/en).
**Приоритеты:** надёжность + скорость.

| Фаза | Название | Содержание | Настройка |
|------|----------|-----------|-----------|
| **1 (MVP)** | Ядро | Инфраструктура, модерация (`/ban /mute /kick /warn`), варн-система, антиспам (ссылки/форварды/стоп-слова), капча, приветствия | Командами в группе |
| 2 | Ограничения | Антифлуд, запрет медиа/стикеров для новичков, ночной режим | Командами в группе |
| 3 | Контент-реакции | Фильтры/триггеры на ключевые слова, авто-ответы, заметки (`/note`) | Командами в группе |
| 4 | Статистика | Активность участников, топы, отчёты, экспорт | Командами + отчёты в ЛС |
| 5 | Расписание | Отложенный и повторяющийся постинг | Командами в группе |
| 6 | ЛС-меню | Настройка всех фич через inline-меню в личке с ботом | ЛС inline-меню |
| 7 | Веб-панель | Дашборд с авторизацией через Telegram Login, настройка мышкой | Веб |
| 8 | Продвинутое | Федерации чатов, репорты, полировка | Все |

Порядок фаз можно менять; зависимости минимальны, но фазы 2–5 опираются на инфраструктуру и модель настроек из MVP.

Промпты фаз лежат в этой же папке: `phase-01-mvp.md`, `phase-02-*.md`, …
