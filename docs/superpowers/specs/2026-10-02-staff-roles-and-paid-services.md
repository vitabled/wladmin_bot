# 2026-10-02 — Роли персонала + платные услуги (закреп / досрочная публикация)

Статус: **одобрено владельцем** (устно, 2026-10-02). Реализация — ветка `feat/staff-roles-and-paid-services`.

## 1. Требования владельца (дословно)

> «Пусть бот @whitemarketadminbot будет отвечать админкой только мне и моему рабочему аккаунту, а также пользователям, которых я добавлю как администратора или модератора в бота.
> Для всех остальных пользователей сделай интерфейс, который позволит заказать закреп, а также купить возможность досрочно опубликовать объявление. Напоминаю, в заданных ветках @whitelistsmarket можно писать лишь раз в 6 часов.»

## 2. Решения владельца (ответы на уточнения)

| Вопрос | Ответ |
|---|---|
| Оплата | **Telegram Stars** + **Crypto Bot** (Crypto Pay), выдача автоматически |
| Тарифы по умолчанию | закреп **24 ч — 200 ₽**, досрочная публикация — **100 ₽** (правятся из админки, без кода) |
| Момент выдачи | **сразу после оплаты**, автоматически, без подтверждения админом |
| Где интерфейс | **и в ЛС боту (меню), и кнопками/командой под объявлением в группе** |
| Персонал | личный `1782827633` (owner) + рабочий **`7176227239`** (admin) + добавленные владельцем админы/модераторы |

## 3. Роли персонала

Единый реестр ролей — источник истины для админ-доступа:

- роли: `owner` > `admin` > `moderator`;
- таблица `staff_members`: `user_id` PK, `role`, `title` (nullable), `added_by`, `added_at`, `is_active`;
- сиды из env при старте (идемпотентно): `OWNER_ID` → `owner`, `DEFAULT_STAFF_IDS` (CSV) → `admin`;
- сервис `bot/services/staff.py`: `get_role(session, user_id)`, `is_staff`, `require_role`, `add_staff`, `remove_staff`, `list_staff`; кэш в Redis (`staff:{user_id}`, TTL 60 c) со сбросом при изменении;
- middleware `AdminMiddleware` дополнительно кладёт в `data`: `staff_role`, `is_staff`; фильтр `IsStaff(min_role)` для роутеров.

**Гейт админки (обязательно):**

- ЛС-меню админа (`bot/handlers/dm_menu.py`), админ-команды в ЛС (`/menu`, `/settings`, `/stats`, `/top`, `/schedules`, `/addtowl`, …), все `dm:*`-колбэки — **только для `staff_role != None`**;
- веб-панель (`bot/web/auth.py`, `bot/web/api.py`, `app.py`): вход разрешён только пользователям с ролью (`allowed_dm_ids` сохраняется как доп. белый список, но доступ = staff);
- `PrivateAccessMiddleware` больше не «глушит» посторонних в ЛС: **все** пользователи получают пользовательский интерфейс, а админ-разделы закрыты фильтром `IsStaff`;
- дерево команд (`bot/commands.py`): персоналу — полный список, остальным — только `/start`, `/help`, `/services`, `/scam`;
- **в группах модерация не меняется** (модерация доступна админам чата, как сейчас) — это осознанно, живые группы не ломаем.

**Управление персоналом** — раздел «👥 Персонал» в админ-ЛС-меню: список, добавить/снять (по id или @username), смена роли. Отдельный FSM `DmStaff`.

## 4. Платные услуги

### 4.1 Каталог и тарифы

Таблица `service_tariffs`: `id`, `chat_id` (nullable = глобальный дефолт), `kind` (`pin` | `early_publish`), `price_rub`, `price_stars` (XTR, целое), `price_usdt_minor` (центы), `duration_hours` (для `pin`, дефолт 24), `is_active`.

Дефолты (создаются при первом запуске): `pin` — 200 ₽ / 150 ⭐ / 2.10 USDT, 24 ч; `early_publish` — 100 ₽ / 75 ⭐ / 1.05 USDT.
Пересчёт ₽ → ⭐/крипта по константам `RUB_PER_STAR=1.33`, `RUB_PER_USDT=95`; админ может переопределить любую из трёх цифр вручную.

### 4.2 Заказы

Таблица `service_orders`: `id`, `user_id`, `chat_id`, `topic_id`, `message_id` (nullable), `kind`, `status` (`pending|paid|active|consumed|expired|cancelled|refunded`), `price_rub`, `price_charge`, `currency` (`XTR|USDT`), `provider` (`stars|crypto`), `provider_payment_id`, `payload` (уникальный, ключ сверки), `created_at`, `paid_at`, `expires_at`, `meta` (JSON).

### 4.3 Оплата

- **Stars**: `send_invoice(currency="XTR", provider_token="")` + хендлеры `pre_checkout_query` (всегда ok после валидации payload) и `message.successful_payment` → немедленная выдача;
- **Crypto Pay**: `POST https://pay.crypt.bot/api/createInvoice` (`Crypto-Pay-API-Token` из env `CRYPTO_PAY_TOKEN`, asset `USDT`, `payload`, `expires_in=3600`), кнопка-ссылка на `bot_invoice_url`/`mini_app_invoice_url`; выдача — **поллингом** (`getInvoices?invoice_ids=…`) отдельным тиком планировщика (раз в ~20 с), плюс опциональный вебхук, если задан `CRYPTO_PAY_WEBHOOK_SECRET`;
- если токена провайдера нет — провайдер выключается, в лог пишется одна понятная строка, кнопка не показывается. Никаких падений.

### 4.4 Выдача

- **Закреп (`pin`)**: `pin_chat_message(chat_id, message_id, disable_notification=True)`, статус `active`, `expires_at = now + duration_hours`; по истечении — снятие закрепа (только если закреплён всё ещё тот же message_id) + уведомление пользователя;
- **Досрочная публикация (`early_publish`)**: пасс в Redis `pass:{chat_id}:{topic_id}:{user_id}` (значение — id заказа, TTL 24 ч) + запись `active` в БД. В `bot/services/slow_mode.py` шаг «заблокировано» сначала проверяет пасс: пасс найден → пасс удаляется, заказ помечается `consumed`, сообщение пропускается и время публикации записывается как обычно; пасса нет → прежнее поведение (удаление + «подождите N»);
- пасс работает только в той ветке/чате, где он куплен; на другие ветки не влияет.

### 4.5 Откуда берётся «объявление»

Лёгкая таблица `user_posts`: `chat_id`, `topic_id`, `user_id`, `message_id`, `created_at` — запись сообщений пользователей в группах (без текста), хранить последние 3 на пользователя в чате, старое подрезать. Используется для:
- списка «мои последние объявления» в ЛС-витрине (кнопки — выбор объявления для закрепа);
- в группе: ответ пользователя на своё сообщение командой `/services` (кнопки «📌 Закрепить» / «⚡ Досрочно») либо `t.me/<user>/<msg>`-ссылка.

## 5. Интерфейсы

**ЛС (не-персонал):** `/start` → витрина: «📌 Закрепить объявление», «⚡ Опубликовать досрочно», «ℹ️ Мои заказы», «❓ Как это работает». Выбор объявления → счёт (Stars-инвойс / ссылка Crypto Pay) → авто-выдача → сообщение с результатом и сроком.

**Группа:** ответ на своё объявление командой `/services` → компактная клавиатура → счёт в ЛС (кнопка-диплинк `t.me/<bot>?start=order_<id>`). Служебные сообщения бота в группе самоудаляются (≤60 c), чтобы не мусорить в ветках.

**Админка (DM, только персонал):** новый таб «💰 Услуги» — заказы за период, суммы, статусы, ручная выдача/отмена/возврат, правка тарифов (₽ → авто ⭐/крипта, ручное переопределение), и таб «👥 Персонал».

## 6. Не-цели этой итерации

- веб-панель: изменения ограничиваются гейтом доступа по ролям (новая страница «Услуги» — отдельной итерацией);
- реферальные/бонусные механики, промокоды — нет;
- автосписание/подписки на закрепы — нет.
